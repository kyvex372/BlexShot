# Üçüncü taraf bileşenleri

BlexShot aşağıdaki açık kaynak bileşenlerden yararlanır. Proje kaynak kodu ve PyInstaller spec dosyası, bağımlılıkları değiştirip uygulamayı yeniden paketlemeye olanak verir. Dağıtım yaparken kullandığınız sürümlerin lisans koşullarını inceleyin; bu dosya bileşenlerin kendi lisanslarının yerine geçmez.

| Bileşen | Lisans / kaynak |
|---|---|
| Python | PSF License — https://www.python.org/psf/license/ |
| PySide6 / Shiboken6 / Qt | LGPLv3 / GPLv3 / ticari seçenekler — https://doc.qt.io/qtforpython-6/licenses.html |
| Pillow | MIT-CMU — https://github.com/python-pillow/Pillow |
| OpenCV | Apache 2.0 — https://github.com/opencv/opencv |
| opencv-python-headless | MIT; paketlenen bileşenler için paketin LICENSE-3RD-PARTY dosyası — https://github.com/opencv/opencv-python |
| NumPy | BSD-3-Clause — https://github.com/numpy/numpy |
| MSS | MIT — https://github.com/BoboTiG/python-mss |
| PyInstaller | GPLv2+ ve ticari/kapalı uygulamaların dağıtımına izin veren istisna — https://pyinstaller.org/en/stable/license.html |

Uygulama logosu kullanıcı tarafından sağlanmıştır. Çizim araçlarının ikonları programatik olarak oluşturulmuştur. Windows Segoe UI yazı tipi sistemden kullanılır; projeyle dağıtılmaz.
